## 👨‍💻 About Me

Fourth-year Software Engineering student at **Fırat University**. I build tools for model monitoring, anomaly detection, and infrastructure automation.

I enjoy the operational side of machine learning: understanding how systems behave, detecting problems early, and making deployments easier to manage.

## 🚀 Featured Projects

| Project | What I'm Building |
| :--- | :--- |
| **🛰️ Star-Ops** | Spacecraft health monitoring across a six-satellite simulation. Combines Isolation Forest and LSTM autoencoders for anomaly detection, with KS-test and PSI to monitor model drift. |
| **👻 [GhostCost](https://ghostcost.com)** | Cloud cost optimization SaaS that detects AWS waste and produces evidence-based savings playbooks. Includes **160+ tests** and a Docker-ready CI/CD pipeline. |
